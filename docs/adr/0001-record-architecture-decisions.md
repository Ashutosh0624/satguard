# 1. Record architecture decisions

- Status: Accepted
- Date: 2026-11-01

## Context
Design decisions need to be traceable for reviewers, collaborators and future me.

## Decision
Use lightweight Architecture Decision Records (Michael Nygard format) in `docs/adr/`, numbered sequentially.

## Consequences
Every significant design choice gets a short, reviewable record; superseded decisions are marked, not deleted.
